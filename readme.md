# 2048 小游戏

项目代码位于 [`game-2048/`](./game-2048/)。

- **直接游玩**：用浏览器打开 `game-2048/dist/index.html`。
- **本地运行**：进入 `game-2048`，执行 `npm start`，打开 <http://127.0.0.1:2048>，无需安装依赖。
- **运行测试**：进入 `game-2048`，执行 `npm test`。
- **完整文档**：查看 [`game-2048/readme.md`](./game-2048/readme.md)，包含玩法、快捷键、功能、项目结构和部署方式。

支持方向键 / WASD、触屏滑动、一步撤销、自动存档、最高分记录以及胜利后继续挑战。
