# 一格 · 2048

一个中文界面的 2048 数字小游戏。原生 HTML、CSS、JavaScript 实现，零第三方依赖，无需构建，支持电脑和手机。

## 快速开始

### 方式一：直接打开

双击 `dist/index.html`，使用现代浏览器开始游戏。无需安装 Node.js 或其他软件。

> 不同浏览器对 `file://` 页面存储的支持有所不同。如需稳定保存进度，推荐使用下面的本地服务。存储不可用时游戏仍可游玩，页面会提示进度仅保留至关闭。

### 方式二：启动本地服务

安装 Node.js 18 或更高版本，在本项目目录执行：

```powershell
npm start
```

也可以直接执行：

```powershell
node server.cjs
```

打开 <http://127.0.0.1:2048>。无需执行 `npm install`。按 `Ctrl+C` 停止服务。

端口被占用时，可以在 PowerShell 中改用其他端口：

```powershell
$env:PORT = "3000"
npm start
```

本地服务默认仅监听本机 `127.0.0.1`。如需在手机上游玩，可将 `dist/` 发布至静态网站托管服务，然后使用手机浏览器访问。

## 玩法

- 棋盘大小为 4 × 4，初始随机出现两个数字方块。
- 向一个方向移动时，所有数字会向该方向滑动；相邻且相同的数字合并为两倍。
- 每个方块在一次移动中最多参与一次合并。例如 `2 2 2 2` 向左移动得到 `4 4 空 空`。
- 每次有效移动后，在一个空位置生成新方块：90% 概率为 `2`，10% 概率为 `4`。
- 无效移动不会生成方块、增加步数或覆盖撤销记录。
- 每次合并按合成数字增加得分，例如两个 `8` 合并为 `16`，增加 16 分。
- 合成 `2048` 即获胜，可选择继续挑战更大的数字。
- 棋盘已满且上下左右均无可合并数字时，游戏结束；仍可撤销最后一步。

## 操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 移动 | 方向键或 W / A / S / D；也支持鼠标拖动棋盘 | 在棋盘上上下左右滑动 |
| 撤销 | 点击「撤销一步」或按 Z | 点击「撤销一步」 |
| 重新开始 | 点击「新的一局」或按 R | 点击「新的一局」 |

每次有效移动后可撤销一步；撤销后需要再次有效移动才能继续撤销。有进度时重新开始会弹出确认窗口，按 Esc 可取消。

## 功能

- 中文界面，鼠尾草绿与暖色数字方块，适配桌面与窄屏设备。
- 方块滑动、出现、合并动画及得分浮动提示；遵循系统「减少动态效果」设置。
- 自动保存当前棋盘、分数、步数、继续挑战状态与撤销记录。
- 独立保存最高分；重新开始和撤销不会降低最高纪录。
- 存档格式检查与损坏存档恢复，存储不可用时自动降级。
- 原生重新开始确认对话框、键盘焦点提示和屏幕阅读器状态播报。
- 无外部字体、图片、第三方脚本或运行时网络请求；本地运行无需联网。

存档使用当前浏览器、当前来源的 `localStorage`，键名为 `yige-2048-v1` 与 `yige-2048-best`。不同设备、浏览器或网址之间不会同步；清除站点数据会清除进度和最高分。

## 测试

在项目目录运行：

```powershell
npm test
```

33 项自动测试覆盖四个方向的移动、合并优先级、单步不重复合并、随机生成、无效移动、得分与步数、撤销、胜负判定、继续挑战、存档恢复、损坏数据、键盘与滑动事件、重新开始确认、动画期间输入互斥，以及不同棋盘上的数字总和守恒。交互测试在轻量 DOM 环境运行，不能替代真实浏览器中的布局和触屏体验检查。

## 部署

将 `dist/` 中的全部文件上传至任意静态网站托管服务即可，网站根目录应为 `dist/`，不需要构建命令或后端。

## 兼容性

适用于近期版本的 Chrome、Edge、Firefox、Safari 及其移动浏览器。使用 CSS Grid、Pointer Events、原生 `<dialog>` 与 `localStorage`；不支持 Internet Explorer。

玩法灵感来自 Gabriele Cirulli 的经典 2048，本项目独立实现界面与游戏逻辑。
